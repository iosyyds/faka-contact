# 甜甜发卡 - 虚拟商品自动发卡平台官网

同款发卡平台官网：虚拟商品即拍即发，介绍平台、主营商品、购买流程与联系方式。

## 线上地址

https://iosyyds.github.io/faka-contact/

## 页面内容

- 平台介绍（关于甜甜发卡）
- 主营商品分类（软件激活码、游戏点卡、视频会员等 8 类）
- 购买流程介绍（四步自助购买）
- 常见问题 FAQ
- 联系我们（客服微信 **NBIOSS**，含一键复制）

## 修改方式

- 微信号：编辑 `index.html`，把 `NBIOSS` 替换为你的新微信号
- 微信二维码：把 `index.html` 中的二维码占位框替换为你的微信二维码图片
- 商品分类 / 文案：直接编辑 `index.html` 对应区块

推送 `main` 分支后，GitHub Pages 自动重新构建上线。
